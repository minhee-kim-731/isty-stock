## 절대 깨뜨리면 안 되는 것
이 제품의 신뢰는 "측정할 수 있는 것만 측정한다"는 데서 나와. 다음을 바꾸려면
반드시 이유를 먼저 설명하고 확인받아:

1. 촬영 5조건 게이팅(노출·좌우광량·초점·프레이밍·흔들림). 이게 없으면 같은 피부를
   두 번 찍어도 값이 달라져서 측정이 무의미해져.
2. 영상 주위 링은 중성 백색. 화면빛이 곧 필라이트인데 시안색 빛이 얼굴에 닿으면
   G채널이 올라가 홍반지수(log R/G)가 실제보다 낮게 나와.
3. 3:4 종횡비. 부위 좌표계가 이 비율 위에 정의돼 있어서 바꾸면 측정 부위가 다 어긋나.
4. "수분·탄력은 카메라로 측정 불가"라는 표기. 원리상 불가능한 거라 문진으로 처리하고
   결과지에 구분 표기해. 이걸 흐리면 아는 사람에게 바로 들통나.
5. 진단 결과는 절대 저장하지 않는다. 피부 지표는 GDPR 9조 건강 데이터라서
   전시 부스가 감당할 수 있는 요건이 아니야. D1에 들어가는 건 연락처뿐이고,
   결과지는 /api/informe 가 메일로 중계만 하고 사본을 안 남겨.
6. index.html 에는 <!doctype>과 <head>가 없어. Artifact로도 게시할 수 있게 일부러
   뺀 거고, 자체 배포용 완전 문서는 build.mjs 가 만들어. viewport 메타가 없으면
   모바일이 980px로 렌더링되고 스페인어 악센트가 깨져.

- 배포·동작 확인 끝. 3개 언어 미번역 키 0건.

## 작업 방식
- 배포: cd espejo-prototipo && node build.mjs && npx wrangler deploy
- 카메라 없이 결과지 확인: 콘솔에서 ESPEJO_DEMO()
- 코드 주석은 스페인어야. 왜 그렇게 했는지가 적혀 있으니 고치기 전에 읽어.
- 커밋 메시지와 나와의 대화는 한국어로 해줘.
- 측정 로직(engine.js)을 건드렸으면 반드시 합성 얼굴로 검증하고 수치를 보여줘.
  이전에 이렇게 잡은 버그가 여러 개야: 마스크 밖 0값이 섞인 배경 블러, 전역 임계값이
  정반사 주변에서만 과발화한 것, 백그라운드 탭에서 setTimeout이 얼어 화면이 멈춘 것.

## 참고 — 계정별로 무엇이 옮겨가고 무엇이 안 옮겨가나

| 항목 | 다른 계정에서 |
|---|---|
| 소스 코드 | ✅ 같은 맥이면 그대로. 다른 기기면 저장소에서 받기 |
| 라이브 URL | ✅ 공개 주소라 누구나 접속 |
| Cloudflare 배포 권한 | ⚠️ 멤버 초대 또는 재로그인 필요 (위 (a)/(b)) |
| D1에 모인 이메일 | ⚠️ Cloudflare 계정에 종속 |
| Claude 대화 기록 | ❌ 계정별로 분리됨 — 그래서 이 프롬프트가 필요 |
| Claude 메모리 | ✅ 기기에 저장되므로 같은 맥이면 따라옴 |
| Artifact | ❌ gmail 계정 소유. 실사용은 라이브 URL을 쓰면 되므로 미리보기용 |
